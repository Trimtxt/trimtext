# Trim[Txt]

**A fast, ad-free, 100% client-side text and whitespace sanitizer.**

👉 **Try it live:** [https://trimtxt.com](https://trimtxt.com)

---

### Why TrimTxt?
Most free online text cleaners are cluttered with intrusive pop-up ads or silently send your pasted text to a backend server. **TrimTxt** runs entirely inside your browser using dependency-free HTML, CSS, and vanilla JavaScript—your code, logs, and proprietary text never leave your computer.

### Features
* 👨‍💻 **Dev Mode:** Strips trailing whitespace and caps runaway line breaks while strictly preserving code indentation and Markdown blocks.
* 🤖 **AI Sanitizer:** Instantly fixes erratic line wraps, spacing artifacts, and broken paragraphs copied out of ChatGPT, Claude, or PDFs.
* 📊 **Bulk Strip:** Collapses all whitespace and line breaks into a single clean string for rapid database and CSV uploads.
* 🔒 **Zero Tracking:** No cookies, no analytics scripts, no databases, and no sign-ups required.

### Built With
* HTML5 & CSS3 (Dark-mode responsive workspace)
* Vanilla Client-Side JavaScript (Zero external dependencies)
